# svitlo — сторінка для підчерги 4.1

## Файли
- `index.html` — адаптивна сторінка для телефону.
- `schedule.json` — дані графіка, які сторінка читає.

## Публікація на GitHub Pages
1. Завантажте `index.html` і `schedule.json` у корінь репозиторію `dima119112/svitlo`.
2. Відкрийте **Settings → Pages**.
3. Виберіть **Deploy from a branch**, гілка `main`, папка `/ (root)`.
4. Дочекайтеся завершення deployment і відкрийте `https://dima119112.github.io/svitlo/`.

## Важливо
Інтерфейс готовий, але автоматичне отримання графіка ще не налаштоване. `schedule.json` навмисно має статус `unavailable`, тому сайт не вигадуватиме графік. Перед використанням потрібно підключити й перевірити автоматичне джерело даних.
