# Автоматизація графіка для svitlo

Цей пакет додає GitHub Actions, який кожні 15 хвилин намагається зчитати офіційну таблицю та оновити `schedule.json`.

## Як додати до репозиторію

1. Розпакуйте архів.
2. У репозиторії `dima119112/svitlo` натисніть **Add file → Upload files**.
3. Завантажте `index.html`, папку `scripts` (із `update_schedule.py`) і папку `.github/workflows` (із `update-schedule.yml`) у корінь репозиторію. Дозвольте браузеру вибрати папку `.github`, якщо запитає.
4. Натисніть **Commit changes**.
5. Відкрийте **Settings → Actions → General** і переконайтеся, що дозволено GitHub Actions. У розділі workflow permissions має бути доступ на запис вмісту репозиторію; workflow просить `contents: write`.
6. Відкрийте вкладку **Actions → Update electricity schedule → Run workflow**, щоб виконати першу перевірку вручну.
7. Перевірте журнал запуску. Якщо парсер успішний, він оновить `schedule.json` автоматично. Якщо структура або кольори на сайті змінилися, запуск завершиться помилкою й не запише здогаданий графік.

## Важливо
Це перша автоматизація, і її потрібно перевірити на реальному запуску GitHub Actions. Сайт оператора може змінювати HTML/CSS. Якщо workflow завершується помилкою, відкрийте лог і виправте селектори/розпізнавання кольорів. Не покладайтеся на графік, якщо сторінка показує, що дані недоступні або застарілі.
